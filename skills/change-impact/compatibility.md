# Compatibility

Status: unreleased original portable Agent Skill, version 0.1.0. The entry point uses plain Markdown and flat-string portable metadata; no host-specific extension is required.

Procedure assumes the operator can read a local Git repository and use ordinary filesystem/Git read operations. It does not require a runtime package, network access, credentials, account access, or repository execution. No native loading, activation, or complete-task behavior has been exercised or claimed. Automated filesystem distribution is qualified separately from native activation; it does not execute the reviewed repository or establish impact-analysis accuracy.

Read-only review is the default. The user must explicitly authorize execution before running repository tests/builds/scripts. Output creation is limited to exactly two reports in a fresh approved external directory; this skill does not authorize modifying the analyzed repository.
