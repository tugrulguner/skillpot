# Compatibility and verification boundary

This portable Markdown skill uses ordinary host file, retrieval and calculation tools.
It has no custom runtime, classifier, executable script or required service. The normal
review procedure can stay offline. Optional public research requires its own explicit
source boundary and permission.

Automated distribution is qualified separately from task success. The existing skills
CLI 1.7.6 was exercised with Node 22.23.4 in an owned isolated home and project. It
installed only the selected bundle for Claude Code, Cursor, Codex and Hermes agent
locations, retained all eight files including the optional fictional sample inputs,
preserved an unrelated sibling and removed only the selected skill when requested.
These are installer/file-placement observations, not native client activation or
factual-review trials. Source pin and final public-install replay belong in the
[distribution guide](../../docs/claim-check-first-use.md), not an implicit latest-main
installation. The installer needs Node.js 22.20+ and Git; neither is required merely
for a host to read and follow already installed instructions.

Metadata/resource checks and authored fixture consistency do not establish native
host activation, automatic selection, factual-review accuracy, security enforcement,
or success on a new task; those are not established here. No model, native client,
product task or account/authentication probe is required or claimed. Tests must not
modify active skill stores or another registered profile.

Instruction version 0.1.0 is unreleased and absent from stable SkillPot v0.4.1.
Installing this current-source bundle does not publish a new collection or replace
existing user edits. Inspect installer behavior and scope before reinstalling/updating;
automation is not a guarantee that edited files are preserved.
