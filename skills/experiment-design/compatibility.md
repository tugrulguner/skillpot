# Compatibility

- **Status:** original current-source bundle, instruction version 0.1.0; not included in published SkillPot v0.4.1.
- **Format:** portable Agent Skills entry point with relative Markdown assets; metadata uses flat string values and a description within the 60-character SkillPot limit.
- **Requirements:** a host that can read supplied files and create a new report in an explicitly approved external destination. No runtime dependency, network access or model is required for planning.
- **Scope:** offline source/resource and authored-fixture integrity checks only. Optional input-only practice contains no expected output or oracle.
- **Not established:** native loading by any host, execution permission, experiment validity, causal conclusions, task efficacy, universal reliability or improved outcomes.
- **Authority:** inspection and planning only by default. Repository searches, commands, dependency installation, services, credentials, model/client use, experiments, target edits and resource spending need separate authorization. The workflow is not a sandbox. Merge, publication and release are separate.
