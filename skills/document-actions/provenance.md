# Provenance and maintenance

This is an original SkillPot extraction procedure and original templates. Maintainer:
`tugrulguner`; version `0.1.0`; source-only and unreleased. Original contributions use
the existing [repository license](https://github.com/tugrulguner/skillpot/blob/524d3a06303362aaafae0fbfdf2ebae38782875e/LICENSE).
No text, template, or code is copied or adapted from the comparison sources below.

## Public comparison sources

The bounded source audit inspected these immutable public snapshots. They are
comparisons, not bundled instructions or runtime dependencies:

- [GitHub Awesome Copilot meeting-minutes](https://github.com/github/awesome-copilot/blob/5269f7ea2d6c3a9bfda5ed878b6726cf509121fd/skills/meeting-minutes/SKILL.md): meeting-specific minutes/action fields, unavailable-field handling, and publishing/task-creation workflow. The example permits implied owners/dates; document-actions instead preserves only source-stated assignments and verbatim deadlines.
- [Awesome Copilot WorkIQ guidance](https://github.com/github/awesome-copilot/blob/5269f7ea2d6c3a9bfda5ed878b6726cf509121fd/skills/workiq-copilot/SKILL.md): account-connected organizational queries, excluded here.
- [Google Workspace CLI email-to-task](https://github.com/googleworkspace/cli/blob/cd3697e07eb520056dcf142d0c7439bbb9ba32e9/skills/gws-workflow-email-to-task/SKILL.md): service-backed task creation, not imported or executed.
- [Microsoft Skills](https://github.com/microsoft/skills/tree/3f5b461b2314e01c400564051e92469114c5b68f): repository inventory/README comparison, not an extraction implementation source.

No private/local skill store, account data or unpublished procedure supplied source
material. Public readability is not a blanket claim about every upstream directory.

## Maintenance

Maintain explicit extraction categories, assignment-versus-acceptance separation,
field-level evidence, verbatim deadlines, conflicts, partial coverage and artifact-only
authority together. Recheck source and output-contract changes with the authored
example and source tests. Do not treat comparison-source changes as automatic updates
to this original workflow. Installed operation needs only this selected directory;
the optional repository example is not an implicit dependency. Structural checks are
not observations of model behavior, native activation or better task performance.
