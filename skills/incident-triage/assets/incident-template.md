- Operational incident status: observed state or Unknown; report completion does not imply resolution
- Classification: development/build/verification / runtime / infrastructure/setup / expected refusal / unknown
- Impact and severity: observed evidence or unknown; applicable impact policy:
- Agreed source roots, read budget, cutoff, privacy rules and output location:
