# Questions needed to use the extracted actions

## Actionable clarifications

### Q1 — Specific question

- Related item/source: A1 / U1 / S1:locator.
- Missing or contradictory claim: ...
- Question: the precise ownership, timing, authority, classification or coverage issue.
- Why it matters: what cannot be interpreted or followed through without the answer.
- Resolver: source-stated authority/person/team / Unknown (do not assign someone).

If there are no material clarifications, state “None identified within the supplied
scope” instead of a generic questionnaire. Missing meeting metadata alone is not a
reason to ask questions about a usable specification. Cite shared evidence once;
reference the item in actions.md rather than duplicating its complete record.

## Coverage limitations

State unreadable/missing permitted sources and how they limit completeness. Do not
invent tasks to compensate or claim all obligations were found. This file requests
clarification; it does not message a person, assign work or accept a commitment.
