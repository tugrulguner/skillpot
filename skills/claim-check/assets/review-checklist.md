# Claim-check completion checklist

## Scope and safety
- [ ] Draft/version, cutoff, jurisdiction/product version, approved source boundary, output permission and stop condition are explicit.
- [ ] Default remained supplied-only; public research occurred only under explicit bounded authorization. Confidential material was not uploaded; no private account, credentials, installation, messaging, publication, or external action was used.
- [ ] Both exact outputs were checked before writing; file, directory, live symlink and dangling symlink collisions caused refusal before either write. Existing/interrupted outputs were preserved.

## Sources and atomic claims
- [ ] Standalone source inventory identifies source, version/date, access/read limits, retrieval date only if retrieved, author/speaker, methods/authority and independence where known; evidence cross-links to it.
- [ ] Quotations/paraphrases and precise locators were checked against fully read source text. Missing attachments, snippets and unreadable passages are not represented as read.
- [ ] Each factual proposition has an atomic record. Attribution is distinct from truth. Mixed claims split event occurrence, independence, reported finding, and underlying proposition as applicable.
- [ ] Conflicts retain both sides and counterevidence; no vote, recency shortcut, or silent resolution. Missing support is not called false.
- [ ] Every verdict is exactly Supported, Overstated, Contradicted, or Unresolved and has a proposition-specific reason and limitations. No confidence score or accuracy percentage is invented.
- [ ] Required arithmetic was actually executed with inputs, units, formula and result retained; if not executable, the claim is Unresolved, not a guessed calculation.

## Independent draft coverage reconciliation
- [ ] Re-read the complete readable draft to build the paragraph assertion inventory independently of the ledger.
- [ ] Every paragraph maps to claim IDs, reasoned exclusions, or explicit unchecked content, including nonfactual paragraphs and unreadable gaps.
- [ ] Every ledger/exclusion ID maps to the correct draft paragraph; no omitted proposition, orphan, duplicate, wrong-paragraph mapping, or silently collapsed facet remains.
- [ ] **Event performance:** if a draft says an audit/review occurred, separately test whether it was performed/completed; commissioning alone is not performance evidence.
- [ ] **Independence:** independently assess independence; preserve a source's “independent” characterization as attribution unless independently supported.
- [ ] **Reported finding:** separately check whether the audit/review actually reported the stated finding; a missing report cannot establish the report's conclusion.
- [ ] **Underlying truth:** assess the underlying proposition's truth separately from audit/review performance, independence, and reported conclusion.
- [ ] These checks are semantic distinctions, not prescribed claim IDs or mandatory audit claims. Matching literal spans, counts, or an authored expected example does not prove completeness or truth.

## Outputs and bounded handoff
- [ ] Exactly `review.md` and `claims.md`; both reopened and cross-checked.
- [ ] Review findings link to ledger IDs and propose only minimal supported local edits. Corrections remain proposals; no wholesale draft, unsupported stronger correction, or unrequested argument.
- [ ] Partial access/coverage, unresolved items, evidence limits and owner follow-up are explicit.
- [ ] Handoff says reviewed within scope, not factually certified or ready to publish; owner retains approval/publication authority.
