# Compatibility

This is a portable, source-only Agent Skills bundle. It requires a host that supports the standard `SKILL.md` entry point and linked Markdown/text resources; it uses no host-specific tool names, scripts, runtime dependencies, network access, or hooks. The host supplies file inspection and any explicitly authorized execution capability. Instructions do not enforce the host's permission boundary.

Status: source authored and resource links are structurally validated by the repository source checks. No native installation, harness activation, model trial, or task-efficacy test is claimed. Read-only inspection is the default; execution requires explicit bounded authorization and command/side-effect review.

The optional practice packet contains only input text and a neutral task prompt. It omits the proposal's expected report and all oracle/case/verdict materials. Its source illustrations are inert authored examples with explicit comments; do not execute them.
