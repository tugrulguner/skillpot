# Before reporting an extraction

Reopen both artifacts and compare them with the supplied sources. This checklist is
an instruction for review, not an automatic semantic validator.

- **Retain each known field.** Review completed/cancelled items as carefully as outstanding
  ones. Preserve a stated owner even when the deadline is unknown. Do not replace several
  fields with a blanket Unknown when only one fact is missing. Check ownership stated
  inside a possessive phrase (for example, "Rin's task was cancelled") before saying
  no owner was supplied; preserve the named task holder, not a proposal's suggester.
- **Check source-item coverage.** List the supported underlying tasks/requirements from
  each source and match each to its canonical actions.md record. Unknown owners or dates
  must not make a requirement disappear into questions.md or a coverage paragraph.
  Owner/deadline conflicts affect those fields, not an otherwise explicit assignment
  category; a status conflict is what can prevent outstanding/historical classification.
- **One item, one canonical record.** Check underlying source IDs across every section,
  not just output IDs. A status conflict belongs only in unresolved items. Remove a
  duplicate historical/outstanding record; a disclaimer does not repair its placement.
  A short cross-reference to the canonical unresolved ID is enough elsewhere.
- **Preserve supported distinctions.** Assignment is not acceptance. A reported completion
  time is not a deadline. A planned condition has not necessarily occurred. Keep proposal,
  historical and unresolved placement consistent with the evidence.
- **Check citations and wording.** Resolve locators and separately sourced fields, retain
  all competing claims, and preserve deadline wording without normalization.
- **Keep questions useful.** Link material questions to canonical item/source IDs and
  explain missing-source coverage without inventing requirements.
- **Finish a refusal clearly.** When a selected output exists or is a symlink, preserve
  it, name the colliding targets and explicitly request a fresh approved location.
  Do not choose the replacement path, clean up, or claim extraction succeeded.
