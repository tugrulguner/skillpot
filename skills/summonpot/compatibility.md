# Compatibility

Current guide pin: `739d980dca48657a839e8f6a19649bfb6f54da80`. Published
[Summonpot v0.14.0](https://github.com/tugrulguner/summonpot/releases/tag/v0.14.0)
is commit `4c3df451e35e6d15e6b068f42bb4189d7777d7ef`; its consumer guide differs.
Authenticated application context is documented from v0.13.0 and the narrow
exactly-one-producer-choice optimization from v0.14.0. The broader multiple-choice
extension is explicitly unreleased in current source. Authentication, authorization
and any deliberate disclosure of context through operation results remain application-owned.

Historical [native Hermes installation, listing and selective removal](../../evaluations/modepot-project-skills/native-install-001/README.md) exercised the earlier package pin. Those installed instruction/reference/license bytes matched that earlier source; this refresh runs no new installer, host session or model trial.

A [bounded assisted consumer replay](../../evaluations/modepot-project-skills/consumer-tasks-001/README.md) used a non-editable 0.12.0 install from the prior pin (not the refreshed source) on macOS arm64/CPython 3.12.13. An eligible deterministic Operation endpoint passed real HTTP, validation, capability argument/count and invalid-registration checks. A raising guard protected the actual model-backed branch and was not entered; no live provider call or fabricated provider result was used. The initial editable run, incomplete logs and incorrect parent guard remain disclosed.

This is not native model activation, the provider-backed execution path, another host, broad runtime compatibility or measured usefulness. Host permissions and behavior vary.
