# Review checklist

- [ ] Source roots, read budget, privacy/redaction, exact external destination and two filenames agreed before inspection/write.
- [ ] Destination and both file paths checked for existing files/directories and live or dangling symlinks; exclusive creation used, with no overwrite or fallback.
- [ ] Read-only scope maintained; every extra command had explicit command list, budget and timeout; actual receipts recorded.
- [ ] No tests/imports/target execution, network, installs, accounts, production access, spend, retry, mitigation, restart, deploy or issue post without separate explicit authority.
- [ ] Symptoms/impact are observations; unknown impact/severity and classification are not invented.
- [ ] Run-head, actual checkout and synthetic merge distinguished; artifact, revision, environment and source identities pinned without repairing unknown IDs.
- [ ] Missing, truncated, mixed-generation, changing and uninspected sources recorded; coverage claim limited to actual inspection.
- [ ] Hypotheses include support, contradiction and next check; suspected cause is not mislabeled demonstrated mechanism.
- [ ] Timeline links each event to source and preserves original precision/timezone; event/collection/notification distinguished; uncertain clocks/partial order explicit.
- [ ] No fabricated events or causal claims from concurrent spans; “not reproduced” is not “fixed.”
- [ ] Raw log export avoided; originals and redacted derivative identities recorded; no unsupported complete-privacy claim.
- [ ] Reopened exact `incident.md` and `timeline.md`; locators, source identity, status and agreed scope rechecked.
- [ ] Exactly two reports in authorized directory; partial/interrupted artifacts preserved; blocker report only separately authorized.
- [ ] Gaps, permissions and not-run actions included; no diagnosis forced by incomplete evidence.
- [ ] Correct counter-trigger: not a performance investigation, bug-repro, readiness audit, full postmortem or remediation.
