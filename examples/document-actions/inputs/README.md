# Offline fictional example packet

This is a wholly invented, publishable example of extracting source-supported actions from a bounded packet. It is not copied from primary sources and is not an observed agent run.

- [`task.md`](task.md): instructions for the input/output boundary.
- [`notes.md`](notes.md): the only source document, with stable paragraph locators `[N01]`–`[N11]`.

Copy the contents of this `inputs/` directory into the project's `document-actions-input/` directory. Expected artifacts and the verifier are deliberately outside `inputs/` and must not be included in the task packet.
