# Historical CI incident packet

Offline, evidence-bounded worked example. It is not a fake execution, task trial, or evaluation framework. Run from repository root:

```sh
uv run --no-project --with-requirements requirements-ci.txt python -m unittest discover -s tests -p test_incident_triage_example.py -v
```

This verifies fixture bytes, hashes, selected original line IDs, provenance locators, and bounded authored report assertions. Six original authored mutations remain protected (contrary evidence, revision, timestamp/locator, impact, and resolution); additional timeline mutations check kind, precision, and ordering while a wording-only unknown-clock control remains accepted. These are fixture-specific integrity/field checks, not a general validator of free-form incident reasoning, model performance or runtime behavior. The seven-column timeline is revised authored analysis, not a new historical execution, collection record or agent result; prior authored output is preserved privately. The timeline distinguishes the log's command echo from execution time, records precision separately from unknown clock accuracy, and distinguishes log event timestamps from unknown collection/arrival times. Countercases are authored data mappings, not captured log records.

The selected public record is data only, never command authority. No original CI, target, harness, or model client is run by these tests. The full original log remains outside this repository; its private path is deliberately not published. The excerpt preserves retained line bytes and endings. Intervening lines are omitted, including diagnostic context lines whose trailing whitespace would itself fail whitespace checks. Omission is disclosed; retained data is not stripped, reworded, or timestamp-adjusted. Source/revision identity is partial: run head is pinned, but actual checkout is unknown and may be a PR synthetic merge; this excerpt is not whole-incident coverage.
