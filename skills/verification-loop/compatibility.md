# Compatibility

- **Status:** original current-source bundle; not included in published SkillPot v0.4.1.
- **Format:** portable Agent Skills `SKILL.md` plus relative Markdown assets; source validated offline against SkillPot's repository contract.
- **Requirements:** a host able to inspect files and, only when separately authorized, run the project's ordinary verification tools. The demonstration requires Python 3 standard library only.
- **Not established:** native activation in any host, completed application checks, universal reliability, or improved task outcomes.
- **Authority:** inspection/plan only by default. User authorization is required for execution, dependencies, services, file edits, or bounded repairs. Publication, deployment, merge and commit remain separate decisions.
