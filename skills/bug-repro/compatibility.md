# Compatibility

The procedure is language-neutral. Select artifact extensions and commands appropriate to the case, but do not infer permission or compatibility from a language/runtime name. Exact target bytes, import location, runtime, and dependency versions are recorded as observed or unknown. No package installation, network access, account, hook, import, or repository execution is implicit. A result is specific to its recorded environment and input; incompatible environments are not proof of a bug. No known-fixed baseline is assumed.

Version 0.1.0 is unreleased and absent from the published v0.4.1 collection. Source-contract checks and executions of an authored fictional example qualify their stated scope only: no native agent loading, automatic activation, real-product reproduction or general model effectiveness is established. Installer filesystem verification is distinct from executing a reproduction task.
