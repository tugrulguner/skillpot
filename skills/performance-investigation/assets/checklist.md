## Optional discriminating contrast: projection-path H1

For the practice packet's H1 (candidate projection-path cost versus run/order or observer variation), propose a matched projection-on/off ablation only if an owner separately authorizes it. Keep the verified artifact and contract, workload, runtime, environment, measurement boundary, and healthy response/error control fixed; balance/interleave order and record observer configuration/budget. Predict beforehand: if projection cost is causal, the disadvantage should track projection-on across matched order and repeat observations and narrow under projection-off; if order/environment explains it, the result should track run position rather than projection state; if observer/extraction explains it, consistent raw-record recomputation and an observer-off control should change or fail to change the contrast as predicted. Null alternative: no stable difference under either state after matching. Even a positive result localizes only this tested contrast; interactions, unobserved runtime state, artifact binding and observer overhead may remain ambiguous. This is a proposed design, not an implemented toggle, performed ablation, or an invented timing receipt.
