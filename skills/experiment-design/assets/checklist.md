# Experiment-design review checklist

Use against the completed `experiment.md`. A checked box means the report names evidence; it does not prove the premise true.

- [ ] Exactly eight required H2 headings, spelled and ordered as in the template.
- [ ] Exact decision, owner, population, comparator, outcome, threshold and consequences; missing decision-changing values block rather than invite defaults.
- [ ] Bounded read/evidence permission, provenance, freshness, unread material and explicit assumptions.
- [ ] Multiple plausible explanations have discriminating observations, falsifiers and residual ambiguity.
- [ ] Contrast/design is justified against cheaper adequate alternatives; every phase can change a decision, validity or interpretation.
- [ ] Matched conditions, intentional difference, identity/runtime/correctness/semantic invariants and verification are explicit.
- [ ] Assignment/order/block/reset rationale is tied to nuisance variation; no default design is assumed.
- [ ] Experimental unit, analysis unit, independent repetitions and within-run measurements are not conflated; precision/power claims are bounded.
- [ ] Each control has function, expected observable and failure consequence; scientific controls differ from validator tests.
- [ ] Full matrix has unique keys, all phases (including calibration/smoke), explicit measurement units/boundaries and denominators.
- [ ] Recomputed cell/time totals agree; unknown setup/control costs are not represented as zero.
- [ ] Budgets, authorizers, permissions and stop boundaries are explicit; missing authorization blocks.
- [ ] Frozen analysis covers aggregation, uncertainty (if justified), multiplicity, eligibility, missing/invalid cells and stop rules.
- [ ] No optional stopping, post-result threshold changes, dropped adverse controls or averaged-away required gates.
- [ ] Handoff prioritizes decidable-now, true prerequisites, design-changing unknowns and smallest worthwhile permission-aware next step.
- [ ] Plan version/freeze is prospective; retrospective examples are labeled; execution status explicitly says NOT EXECUTED unless separate evidence exists.
- [ ] Destination is fresh, owned, external, outside target/evidence/installed resources; exclusive directory/file creation refused existing and symlink destinations; only `experiment.md` created.
