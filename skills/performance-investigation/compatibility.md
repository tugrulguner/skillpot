# Compatibility

Portable Agent Skills entry point with flat string metadata; no nested Hermes-specific metadata or host runtime dependency. Intended for hosts that load the standard `SKILL.md` directory format. No live host activation or task-efficacy trial is claimed.

The procedure uses ordinary host file, source-inspection and calculation tools. Reuse existing explicit bounded authorization only after inspecting commands/effects; instructions do not grant permission or sandbox execution. No runner, benchmark client, profiler, optimizer, network dependency or model call is bundled.

Standalone use requires only this directory. All operational resources link within the bundle. The practice packet is optional and input-only; the proposal's expected report/acceptance oracle is excluded.
