# Compatibility and evidence status

This bundle is harness-neutral Markdown guidance with static templates. Its portable metadata and local resource links can be checked offline; no harness/model was launched or tested. Therefore host discovery, agent activation, complete-task behavior, incident accuracy, safety enforcement and usefulness are not established. The host's own tools and permission controls remain authoritative. No OS-specific command or dependency is required. The historical worked example is retrospectively authored analysis of selected real CI records; offline fixture checks do not evaluate an agent. Version 0.1.0 is unreleased and absent from the published v0.4.1 collection. Filesystem distribution checks, when recorded separately, do not establish native loading or task accuracy.
